# personalwebsite

Personal portfolio — built with Next.js (App Router), TypeScript, Tailwind CSS, and Framer Motion.

## Design direction

One page, tight copy, no clutter. Dark, focused palette (near-black background, teal-mint accent for clarity, a warm amber accent used sparingly for human warmth) built around the idea of an engineer who thinks in systems — reinforced by a subtle animated node/graph motif behind the hero.

Currently built: the hero section (intro, positioning line, contact CTAs). More sections (about, experience, projects, contact) are being added incrementally.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Stack

- [Next.js](https://nextjs.org) (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion
